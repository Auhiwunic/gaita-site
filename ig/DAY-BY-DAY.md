# Gaita — Day-by-day posting schedule

Open this each day, post the file listed, paste the caption from `captions.md`. That's it.

**Two anchors:**
- **Pre-launch week** can start any Monday, even before Apple approves (link points to gaita-site until the App Store link is live).
- **Launch week is anchored to L = the day Apple approves.** You can't control that date, so everything in Week 1 shifts to whenever L lands.

**Daily habit (5 min):** post the scheduled item, reply to every comment for the first hour, add one story. First-hour replies are the single biggest free reach lever on a new account.
